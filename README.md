# INFO2130 · გამოსახულებების დამხმარე რესურსები

> **ფრონტ-ენდ დეველოპმენტი · დასკვნითი გამოცდის პრაქტიკული ნაწილი**
> ბოლო შემოწმება: 2026 წლის ნოემბერი

ეს ფაილი **დამხმარეა**: მასში თავმოყრილია ფოტოების წყაროები ბილეთების თემებისთვის. ფოტოები შეგიძლია მოიძიო ნებისმიერ თავისუფალი ლიცენზიის წყაროში, მათ შორის ამ ფაილის გარეთაც. ძირითადი მოთხოვნები ბილეთშია. **ყველა ბმული არ არის გამოსაყენებლად დაშვებული.** შენი ამოცანაა, თვითონ შეამოწმო, რომელი ფოტოს გამოყენება შეიძლება. ეს ფასდება შეფასების კრიტერიუმით სშ9 (ეთიკა და ლიცენზიები).
